# Workspace User Directives & Rules

## STRICT GitHub Pushing Policy
- **STRICT DIRECTIVE**: NEVER execute `git push` automatically under ANY circumstance (even for live server bug fixes, small edits, or troubleshooting).
- ALWAYS keep all code changes 100% local.
- ONLY execute `git push` when the user explicitly issues the command to push to GitHub in their prompt.
- Reason: Avoid unnecessary Render builds and save build credits/time.
